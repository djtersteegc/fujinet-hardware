# FujiPlusCart-Prototype

**This cart is a prototype, and needs further refinement. Note the bodges in fujipluscart_proto0-uart-bodge.jpg !!**

This repo contains the Gerbers, BOM and schematic for the combined ESP32S3 and RP2040 cart intended for the Atari 2600 FujiNet. While this cart works once the bodge is applied, this board needs more layout work done, and any help here would be immensely appreciated. -Thom and Mozzwald
